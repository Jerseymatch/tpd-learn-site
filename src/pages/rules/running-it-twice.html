Running it twice is when the players who are all in agree to deal the rest of the board two times instead of once. Each board is worth half the pot. Basically, you have two different outcomes now, and they're each worth half.

Players do it to reduce their variance. In big pots, with players willing to get it in, they're going to run it twice a lot of the time, so one person's not going home crying as often. You'll see it all the time in cash games where I deal in Texas, especially in PLO. The purist in me likes having one winner, but my priority is keeping the players happy.

The rules: when players can run it twice

  • Only when the action is complete. Every betting decision in the hand has to be over. If two players are all in and two other players still have chips and can still bet, you can't run it twice.
  • Only for the cards still to come. If they're all in on the turn, you can't run anything before the turn. You bring two rivers. All in on the flop, you bring two turns and two rivers. All in before the flop, you run two full boards.
  • Cash games only. You don't run it twice in a tournament.
  • Everyone involved has to agree. Once is the default. If one person says one time, even if there are four people involved, you run it once.
  • Rooms set their own rules. Running it twice is newer than most poker rules. I first saw it about 10 years ago. With newer things like this, and PLO double-board bomb pots, you get different interpretations all over the place. Some rooms only allow it heads-up in certain games: in the Dallas rooms, 1-2 no limit doesn't allow it with more than two players. Split-pot games like Big O and five-card hi-lo usually don't allow it, because you're already quartering people, and running it twice can turn that into eighths. A lot of the time it's the players in those games who say, "We don't want to let anybody run it twice here." Your poker room will give you its rules.

When there's a main pot and a side pot

Generally speaking, if two players are on the side and one player is all in for the main, and the player in the main says one time, it's one time for the whole thing. Some places let the players on the side run it twice for the side pot only, since it doesn't affect the main pot player's pot. In the Dallas rooms where I deal, that situation is a floor call: the supervisor comes over and tells the table how it's going to go, so nobody's confused. They still let it happen. So if one player says once, don't automatically say no to the others. Get the floor and find out what your room does.

Why some rooms don't like it

It takes a lot more time. In a game where the house takes a time rake, the house doesn't care: it makes the same money either way, so if that's what the table wants, that's what you do. In a game with a rake, every minute spent on a second board is a minute not spent on the next hand, and that's why some casinos don't like it. The other players at the table, who aren't in the hand, usually don't want you to run it twice either. It takes longer.

For the players in the hand, the expected result is the same in the long run whether they run it once or twice. It just means fewer hands get dealt.

How it starts: give them the moment, don't ask

When the action is complete in a cash game, slow down a little. Tap the table and say, "Action's complete." Give it a second. Then burn a little slower than you normally do.

  • You don't ask them, "Do you want to run it twice?" Asking is pretty universally not the dealer's job. In some home games the dealer asks "once or twice?" every time. I'm of the school of thought that it violates one player per hand.
  • If they start the conversation, stop everything and wait. You don't get involved in it. If they go back and forth with "How many times do you want to run it?" "I don't care." "You brought it up," it's fine to say, "Guys, come on. What do you want to do?"
  • If nobody says anything, you've done your due diligence. You gave them the space and the opportunity. Burn and bring the card.
  • If they speak up after you burn, but before you've turned a card, it's still fine. That's what the tap is for: it's their cue.

Confirm with everybody

If there was any conversation about it, confirm with every player involved. With two players, you just get each one's consent: "You want to run it twice? You want to run it twice? Okay, we're running it twice."

A rule I love: at Texas Card House, where I deal, when three or more players are in, every one of them gives a thumbs up for the cameras. That eliminates any doubt that people agreed. The last thing anyone wants is to run it twice and then have a dispute about whether everybody said yes. It's not a universal rule, but if your room doesn't require it, it's still a good habit.

Then tell the whole table what's coming, and hold up two fingers: "Two rivers, guys. Two rivers coming up." If it's two full boards, "Two times."

How the dealer runs two boards

You burn before every card, on both boards. This is the part people mix up with double-board bomb pots. In a double-board bomb pot, you burn once and bring two cards for each street. Running it twice, you burn for each one. Some poker rooms might do it differently, so learn yours.

  1. Run the first board as normal. Tap, burn, bring the turn (if it isn't out yet). Burn, bring the river.
  2. Push the first board's cards up. The cards you just brought for the first run move up, about halfway, so the second run can go below them.
  3. Run the second board. Burn, bring the second turn. Burn, bring the second river. The cards already on the board before the all-in are shared by both boards.

So all in on the flop means four new burn cards. All in before the flop, you push the whole board up and run two full boards: burn, flop, burn, turn, burn, river, twice. That's six burn cards total.

If you keep forgetting a burn, here's a routine I gave a student: burn and bring the first turn halfway up, burn and bring the first river, burn and bring the second turn, burn and bring the second river. Putting cards halfway up and then halfway down isn't something you do in any other situation, so it gives you a new cue, and the habit of burning each time sort of happens on its own.

Running out of cards

Count it out before you assume you can run two full boards. Nine-handed PLO with two full boards and all those burns uses every card in the deck, including the bottom card. For a long time the industry rule was never to use the bottom card for anything, and always keep one card on top of the cut card. At Texas Card House, the policy is to use it. And in an eight-handed five-card game, there aren't enough cards for two full boards at all. If players want two full boards and you're not going to have the cards, get a supervisor. Your room may have its own way around it.

The pot: do you need to build it first?

If the players are running it twice, a lot of the time you just leave the bets in front of them. Think about heads-up with one player covered. There are three possible outcomes:

  1. The player with the bigger stack wins both boards and gets all of it. You never had to figure out the short stack's amount.
  2. They each win one board. It's a chop. You push their money back to them and split what's in the middle, and you never needed the amount either.
  3. The short stack wins both boards. That's the only case where you count their stack out and get that amount from the other player.

The proper way, and Texas Card House's policy, is to build the whole pot. With a multi-way all-in and side pots, build the pots first. I bring the short stack's amount in from every player to make the main pot, and leave the extra side amounts in front of the players. Once they've agreed to run it twice, stacking into the middle is fine. If you do run it out before every pot is built, award the main pot first, then work outward. How to build side pots covers that.

Some rooms have a house rule that if there are multiple pots and the players want to run it twice, you call the floor, just to have another set of eyes. I love that. And you're always welcome to get a supervisor to run it twice with you, especially your first few times. There's a lot more work in it.

Reading the boards and splitting the pot

Each board gets half the pot, so you have to say who wins in both cases. Don't start chopping anything up until you need to. First find the winning hand on each board.

  • Read each board on its own. Top board, bottom board. Cards that were out before the all-in play on both. A pair on the board before the run-out is on both boards, which isn't intuitive the first time you see it.
  • Frame by touching the three relevant cards on each board and moving them up and down a little: "Flush," then "two pair." You don't need to line the board up and then frame it. Leave the cards where they are. This isn't universal, but it's easy for everyone to see and easy for you to communicate.
  • Say both results out loud. "Ace high up top, pair of nines on the bottom. That's a chop."
  • Same player wins both, they scoop. Different winners, it's a chop: they take their bets back, and you split the middle.

Quartering across two boards

With three players, one board can chop while the other has a single winner, so someone ends up with a quarter of a pot and someone else three quarters. Work from the outside in. With the main pot already built, settle the side pot between the deep stacks first: if a player is getting quartered there, they just give up half their matching amount. Then chop the main pot in half, give the short stack their half, muck their cards, and split the other half. A shortcut when two players chop the top board and one wins the bottom: give the covered player their bet back, and give half to the bottom-board winner. It's okay to go slow and double-check. Split pots and quartering has the method in detail.

What I correct in class

Paying only one player

A student runs it twice, the boards split, and they push the pot to one player and forget the other one's half. If you left the bets in front of the players, you have to remember to give everybody their money.

One burn per street

A student who's dealt double-board bomb pots thinks you burn once and bring two cards. Running it twice, every card gets its own burn.

Asking the players

A student who deals home games told me the dealer there asks, "Once or twice?" almost every time. In a poker room, don't. Say "Action's complete," give them the moment, and let them bring it up.

How to practice running it twice

  • Deal it on purpose. When you get an all-in in practice, run it twice, especially if you're headed to a room that allows it. We don't spend a ton of time on it in class, so be ready to teach it to yourself once your fundamentals are solid.
  • Practice from all three spots: two rivers, two turns and rivers, and two full boards, with a burn before every card.
  • Set up a three-way all-in with one short stack, and make one board chop.

Common questions about running it twice

Do you have to agree to run it twice?

Yes. Every player involved has to agree. Once is the default, so if one player says one time, it's run once.

Can you run it twice in a tournament?

No. Running it twice is a cash game thing.

Do you burn a card for each board when running it twice?

Yes, you burn before every card on both boards. That's different from a double-board bomb pot, where you burn once and bring two cards. Some rooms do it differently.

Can you run it twice with three players?

In many rooms, yes, if everyone agrees. Some rooms want a thumbs up from every player for the cameras, some want a supervisor there, and some only allow it heads-up in certain games.

Should the dealer ask if players want to run it twice?

No. The dealer says "Action's complete," gives the players a moment, and lets them bring it up.

Does running it twice change the odds?

In the long run, the expected result is the same. It lowers the swings, and it means fewer hands get dealt.
